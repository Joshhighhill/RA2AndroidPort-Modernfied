Implemented changes
-------------------
R-058 Construction Yards: existing touch panel and Deploy command now expose
the existing sell-mission packing transition for permitted ConYards. All
GACNST/NACNST/YACNST mappings checked; human owner, registered UndeploysInto,
skirmish and MCVRedeploys must permit it. Occupied exit prevents starting.
The existing reverse buildup, health ratio and queue/factory cleanup remain.
This adds UNDEPLOY command access, not a new arbitrary move-to-pack rule.

R-060: mobile Slave Miner workers choose reachable free neighbouring cells,
with distinct worker goals, rather than the miner's occupied centre. Goals
that become stale after manager movement can be refreshed at the existing
30-frame stagger; prolonged blockage also allows re-routing. No teleport,
worker deletion, unrestricted direct orders, extra resources or RNG changes.
Deployment clearance also reconsiders friendly blockers stalled over 3s.
Full follower pathing under every map/threat remains a device-test item.

Deployment speech (explicit latest user request): automatic MCV/Slave Miner
deploy attempts use quiet saved mission variants, suppressing CannotDeploy
events both immediately and after a failed delayed arrival. Player Deploy
orders retain failure feedback. AI automatic MCV production uses the quiet
entry point too, as do campaign team-script MCV deployments. Existing
VoiceDeploy is queued from player input actions,
not from automatic infantry deploy state changes. Selection voices, physical
deployment sounds, combat effects and urgent announcements are not muted.
Quiet missions survive format53 save/load. Use same-build multiplayer peers;
old binaries do not understand the new automatic mission values.

R-004/R-014/R-040/R-055 and latest bridge texture report: bridge tank sort
depth is clamped after the deck of its occupied cell even when its continuous
track position trails behind that cell. Previously the deck could overpaint
part of its own on-deck vehicle. Legal ground segments interpolate display Z
between effective source/destination heights; each bridge layer contributes
its own +4. Vehicle/infantry body, shadows and selected-unit pips use the
continuous height rather than an entire 15px cell-height jump. Simulation
height/collision/projectiles unchanged. This is a targeted presentation fix,
not proof that all bridge/slope textures or VXL tilt are now PC-perfect.
Exact failing bridge map and original-PC visual comparison still needed.

Pinch zoom: battlefield-only 0.75x..1.75x scale, with input coordinates and
camera viewport remapped. Production sidebar, shortcut panel, menus and HUD
keep their canvas size. World selection/placement/sensor/target overlays and
beacons scale with the battlefield. Screen resize resets zoom. It does not
change user-selected game resolution or simulation state. Selection tests
at both zoom limits pass. Phone alignment, corner cases and feel still need
device verification; no full graphical --play/emulator run was performed.

Psychic Sensor boundary: selected active sensor now has brighter, two-pixel
dashes instead of the previous solid purple ring. Detection radius, power,
eligibility and enemy-house intent colors unchanged. Mobile readability
enhancement, not a verified reproduction of every PC range-overlay detail.
