# Map Browser / Multi-Map Skirmish — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the engine's single hardcoded map — which the completed hunt proved is a **campaign mission** (`mapsmd03.mix` entry `0x133a0cb2` = `sov07tmd.map`, maps.md §1) — with a real **map browser**: parse the `missionsmd.pkt` manifest, existence-filter it against `multimd.mix`, resolve CSF display names, filter to `GameMode=standard`, list the 91 skirmish maps in the setup screen, load any of them generically (variable dimensions, five theaters), and place houses at the map's real `[Waypoints]` 0–7 starts. Demonstrated by the **19th permanent byte-identity gate `--demo-maps`**. All 18 existing gates stay bit-identical.

**Architecture:** Three new pure `ra2assets` pieces — `PktFile` (`.pkt` manifest decoder), `MapFile::waypoints()/start_waypoints()/start_count()` (NEW fields on the existing parser), and the `TheaterChain` table (per-theater tile mix / control INI / iso palette / art mix / palettes / extension / NewTheater letter). One new pure `engine/` module `maplist.{hpp,cpp}` (registered in BOTH cmake files, host-doctested) holding `build_map_catalog(pkt_text, maps_mix, csf, mode_tag)` — the pkt → **existence filter** → mode filter → CSF-name → stable-sort pipeline — plus `load_yr_map_catalog(dir)`. In `engine/main.cpp`: `load_assets` gains a defaulted `MapSelection` parameter (whose default value is literally today's `mapsmd03.mix`/`0x133a0cb2`) and drives palette/INI/tiles from the `TheaterChain`; `load_ore_art`/`load_building_assets` gain a defaulted `const TheaterChain*` (omitted → TEMPERATE → character-identical candidate walk); `SkirmishConfig` gains `map_file` (`""` → default map) and `use_map_starts` (`false` → today's fan-out); `launch_skirmish` places bases at `a.map.start_waypoints()[k]` when opted in; `make_ai_team_config` gains a defaulted `const MapFile*` for real script waypoints; `SkirmishSetupScene` grows a scrollable map list; and a new `simulate_maps`/`run_demo_maps`/`--demo-maps` gate mirrors the `--demo-skirmish` harness on **`xmp31s2.map`** (SNOW, 70x83, 2 starts, `standard`). Everything reachable only through defaulted parameters that reproduce current behavior, or through new config fields that default off — the 18 gates build worlds directly on the default map and never touch any of it.

**Tech Stack:** C++17, doctest, CMake+Ninja (desktop `build/`, Android `android/` gradle, NDK `D:\android-ndk-r27c`, JDK-21), SDL2 (render/UI only), `ra2assets` (`Ini`, `MixFile`, `CsfStrings`, `base64_decode`, `decompress_mappack`, `MapFile`, `TmpFile`, `theater_candidates`), `ra2engine` (`World`, `Theater`, `SkirmishConfig`, `launch_skirmish`, `Scene`/`run_scene_driver`/`GameScene`/`SkirmishSetupScene`), `build/ra2extract.exe` for the RE-GATE only. namespace ra2assets {

// One map row of a Westwood ".pkt" map manifest [RE: maps.md §2]. The stock
// map list is NOT "every entry in the mix": it is this packet file, an INI with
// a [MultiMaps] index (1=XMP29U2, 2=XMP21S2, ...) and one section per map:
//     [XMP01T4]
//     Description=DESC:MP01DU     ; a CSF string label, NOT a display name
//     CD=2
//     MinPlayers=2
//     MaxPlayers=4
//     GameMode=standard           ; CSV of mode tags
// YR (our target) uses langmd.mix/missionsmd.pkt (21,142 B, entry 480B82E4);
// RA2 uses missions.pkt. NOTE (maps.md §2): MinPlayers/MaxPlayers is the
// LOBBY-facing cap and CAN disagree with the map's [Waypoints] start count
// (6 of 161 maps do) -- the waypoints are the placeable positions.
struct PktMapEntry {
    std::string index_key;    // "1"           -- the [MultiMaps] key
    std::string base_name;    // "XMP01T4"     -- verbatim [MultiMaps] value
    std::string file_name;    // "xmp01t4.map" -- lowercased base_name + ".map"
    std::string description;  // "DESC:MP01DU" -- CSF label; "" if absent
    std::vector<std::string> game_modes;   // lowercased, trimmed GameMode= tags
    int min_players = 0;
    int max_players = 0;
    int cd = 0;
    // Case-insensitive membership test over game_modes (e.g. has_mode("standard")).
    bool has_mode(const std::string& tag) const;
};

class PktFile {
public:
    // Parse a whole .pkt file image (INI text). Never throws on content: a
    // [MultiMaps] value with no matching section still yields an entry (with
    // empty description/modes and zero counts) -- dropping unusable maps is the
    // CALLER's job via the mandatory existence filter (maps.md §2). Returns an
    // empty entry list if there is no [MultiMaps] section.
    static PktFile parse(const std::string& ini_text);

    // Entries in [MultiMaps] file order (the order the original browser lists).
    const std::vector<PktMapEntry>& entries() const { return entries_; }

private:
    std::vector<PktMapEntry> entries_;
};

} // namespace ra2assets

#include "ra2assets/pkt.hpp"
#include "ra2assets/ini.hpp"
#include <algorithm>
#include <cctype>

namespace ra2assets {
namespace {

std::string lower(std::string s) {
    for (char& c : s) c = (char)std::tolower((unsigned char)c);
    return s;
}

std::string trim(const std::string& s) {
    size_t b = 0, e = s.size();
    while (b < e && std::isspace((unsigned char)s[b])) ++b;
    while (e > b && std::isspace((unsigned char)s[e - 1])) --e;
    return s.substr(b, e - b);
}

// Split a GameMode= CSV into trimmed, lowercased tags; empty fields dropped.
std::vector<std::string> split_modes(const std::string& csv) {
    std::vector<std::string> out;
    size_t pos = 0;
    while (pos <= csv.size()) {
        const size_t comma = csv.find(',', pos);
        const std::string tok =
            trim(comma == std::string::npos ? csv.substr(pos) : csv.substr(pos, comma - pos));
        if (!tok.empty()) out.push_back(lower(tok));
        if (comma == std::string::npos) break;
        pos = comma + 1;
    }
    return out;
}

} // namespace

bool PktMapEntry::has_mode(const std::string& tag) const {
    const std::string t = lower(trim(tag));
    return std::find(game_modes.begin(), game_modes.end(), t) != game_modes.end();
}

PktFile PktFile::parse(const std::string& ini_text) {
    PktFile pkt;
    Ini ini = Ini::parse(ini_text);
    // [MultiMaps] values are map BASE NAMES; append ".map" and look them up in
    // the mix chain (maps.md §2). Ini::section preserves file order, and
    // full-line ';' comments (the pkt's ";169=" inactive rows) were already
    // dropped at parse -- so this walk yields exactly the ACTIVE list.
    const auto& index = ini.section("MultiMaps");
    pkt.entries_.reserve(index.size());
    for (const auto& kv : index) {
        const std::string base = trim(kv.second);
        if (base.empty()) continue;
        PktMapEntry e;
        e.index_key = kv.first;
        e.base_name = base;
        e.file_name = lower(base) + ".map";
        // Ini section lookup is case-insensitive, so [XMP01T4] resolves for a
        // "xmp01t4" index value and vice versa. A missing section leaves the
        // metadata defaulted -- the caller's existence filter is what drops it.
        e.description = trim(ini.get(base, "Description", ""));
        e.game_modes  = split_modes(ini.get(base, "GameMode", ""));
        e.min_players = ini.get_int(base, "MinPlayers", 0);
        e.max_players = ini.get_int(base, "MaxPlayers", 0);
        e.cd          = ini.get_int(base, "CD", 0);
        pkt.entries_.push_back(std::move(e));
    }
    return pkt;
}

} // namespace ra2assets

namespace ra2engine {
namespace {

std::string lower(std::string s) {
    for (char& c : s) c = (char)std::tolower((unsigned char)c);
    return s;
}

// CSF values are UTF-16. Every stock map name is ASCII; narrow to char and
// replace any non-ASCII code unit with '?' rather than mangling the string.
std::string narrow(const std::u16string& u) {
    std::string out;
    out.reserve(u.size());
    for (char16_t c : u) out.push_back(c < 0x80 ? (char)c : '?');
    return out;
}

}  // namespace

std::vector<MapEntry> build_map_catalog(const std::string& pkt_text,
                                        const ra2assets::MixFile& maps,
                                        const ra2assets::CsfStrings* csf,
                                        const std::string& mode_tag) {
    std::vector<MapEntry> out;
    const ra2assets::PktFile pkt = ra2assets::PktFile::parse(pkt_text);   // step 1
    for (const ra2assets::PktMapEntry& p : pkt.entries()) {
        if (maps.find(p.file_name) == nullptr) continue;                  // step 2
        if (!mode_tag.empty() && !p.has_mode(mode_tag)) continue;         // step 3
        MapEntry e;
        e.file_name   = p.file_name;
        e.base_name   = p.base_name;
        e.csf_label   = p.description;
        e.game_modes  = p.game_modes;
        e.min_players = p.min_players;
        e.max_players = p.max_players;
        e.display_name = p.base_name;                                     // step 4
        if (csf && !p.description.empty()) {
            if (const std::u16string* v = csf->find(p.description)) {
                const std::string n = narrow(*v);
                if (!n.empty()) e.display_name = n;
            }
        }
        out.push_back(std::move(e));
    }
    std::stable_sort(out.begin(), out.end(),                              // step 5
                     [](const MapEntry& a, const MapEntry& b) {
                         const std::string la = lower(a.display_name), lb = lower(b.display_name);
                         if (la != lb) return la < lb;
                         return a.file_name < b.file_name;
                     });
    return out;
}
