**Goal:** Broaden the narrow engine roster by **16 calibrated, art-present RA2 types** — 4 buildings appended to `kRoster` and 12 units in a NEW `kRosterUnits` content-unit table — make the Allied base **symmetric** with the Soviet one behind a default-false `spawn_base` flag, and prove it all with the **18th permanent byte-identity gate `--demo-roster`**. **Architecture:** Append-only content growth (the CB-5 `GATECH`/`CAOILD` precedent). Task 3 adds a NEW `kRosterUnits[12]` table of `UnitRosterEnt` rows (7 Soviet + 5 Allied) loaded by the EXISTING `load_unit_roster_table` machinery with `full_parse=true`; `resolve_combat_unit` (`main.cpp:613-708`) resolves each unit's weapon/warhead/verses GENERICALLY per-id, honoring `Image=` overrides (APOC→MTNK etc.); `kUnits` (player slots 0-4) and `kSoviet` (AI proxy) are UNTOUCHED, and APOC is promoted to a real content type in `kRosterUnits` (dual prereq NAWEAP,NATECH) while the `kSoviet` APOC proxy is left byte-for-byte alone. Task 5 (optional) threads a default-false `allied_full` through `SkirmishConfig` so the interactive `GameScene` gives an Allied skirmish player a full base while `--demo-skirmish` keeps it false. Task 6 adds the `--demo-roster` gate: `roster_fold` + `simulate_roster` (resolve+assert all 16, spawn via `spawn_base(allied_full=true)` + explicit `add_building` + `add_combat_unit`) + `run_demo_roster` (two-run rendered/headless self-compare, wedge guards, NO pinned literal). Task 7 finalizes (18-gate re-verify one-per-call, RE-PIN the `roster=N` witness counts, arm64 `assembleDebug` + nm-verify, README). `world_hash` (`main.cpp:4528`) folds spawned INSTANCES by roster index + unit cell/hp/alive — NOT the roster table — so append-only growth preserves every existing index and cannot perturb any hash; the base/techtree `roster=N` WITNESS COUNT grows by +4 (both runs agree → deterministic still passes; base/techtree hashes UNCHANGED → re-pin the documented count, not a hash).

struct ResolvedRosterType {
    std::string id;
    int  cost = 0, tech = 0, strength = 0, damage = 0;
    bool is_building = false;
    bool resolved = false;   // cost>0 && tech>0 (units) / present in kRoster (buildings)
    bool spawned  = false;   // an instance of this type exists in the World
};

// [RE: roster.md §2, D3] FNV fold of the roster-launch state. Folds every spawned
// INSTANCE exactly like world_hash (Building{type,cx,cy,hp,state}, Unit{cell_x,
// cell_y,hp,alive}) PLUS a per-new-type resolved sample (cost/tech/strength/damage)
// + the resolved count. A NEW accumulator; world_hash + every prior *_hash
// UNTOUCHED. Both runs fold identical state -> deterministic self-compare.
uint64_t roster_fold(uint64_t h, const ra2engine::World& world,
                     const std::vector<ResolvedRosterType>& types) {
    for (const ra2engine::Unit& u : world.units()) {
        h = fnv_mix(h, static_cast<uint64_t>(u.cell_x));
        h = fnv_mix(h, static_cast<uint64_t>(u.cell_y));
        h = fnv_mix(h, static_cast<uint64_t>(u.hp));
        h = fnv_mix(h, static_cast<uint64_t>(u.alive ? 1 : 0));
    }
    for (const ra2engine::Building& b : world.buildings()) {
        h = fnv_mix(h, static_cast<uint64_t>(b.type));
        h = fnv_mix(h, static_cast<uint64_t>(b.cx));
        h = fnv_mix(h, static_cast<uint64_t>(b.cy));
        h = fnv_mix(h, static_cast<uint64_t>(b.hp));
        h = fnv_mix(h, static_cast<uint64_t>(b.state));
    }
    for (const ResolvedRosterType& t : types) {
        h = fnv_mix(h, static_cast<uint64_t>(t.cost));
        h = fnv_mix(h, static_cast<uint64_t>(t.tech));
        h = fnv_mix(h, static_cast<uint64_t>(t.strength));
        h = fnv_mix(h, static_cast<uint64_t>(t.damage));
    }
    h = fnv_mix(h, static_cast<uint64_t>(types.size()));
    return h;
}
