### Approved scope decisions (spec §Approved scope decisions)

- **Water movement model:** pathed A\* over a WATER passability grid (cell-to-cell, `occ_` one-ship-per-cell) — the SAME machinery ground units use, NOT CB-2's straight-line flight. The core change is parameterizing walkability by a movement domain: ground reads the existing `passable_` (Land) grid unchanged; naval reads a new `water_passable_` grid. The exemplar's locomotor is a distinct naval CLSID `{2BEA74E1-7CCA-11d3-BE14-00104B62A16C}`; whether it is a standalone `ShipLocomotionClass` or Drive-gated-by-SpeedType, and any water-specific pathing, is `[RE-GATE: naval.md §1]`.
- **Walkability parameterization:** a `MovementDomain { Land, Water }` selector. `World` holds two grids: `passable_` (Land, built by the UNCHANGED `build_passability`) and a NEW `water_passable_`. `grid_for(domain)` returns the Land grid for `Land` (the DEFAULT — every existing call site unchanged) and the water grid for `Water`. Structural byte-identity: default Land ⇒ identical grid object.
- **Water-cell identification (NET-NEW foundation, Task 2):** a per-cell **LandType** resolved from the map's tiles. Source is `[RE-GATE: naval.md §2]` — the two candidates the hunt decides between: **(a)** the per-tile `TerrainType` byte in the `.tmp` image header (extend `TmpFile`), or **(b)** classifying a tile's `[TileSetNNNN]` (extend `Theater`). The documented fallback is (a). `main.cpp` (which owns the `Theater`) resolves per-cell LandType and hands `World` a LandType array; `World` builds `water_passable_` from it (`World` stays asset-free). Empty by default ⇒ no water pathing unless the naval path opts in.
- **Passability rule:** a cell is passable for a SpeedType iff its land-type speed % is `> 0`. For CB-3's Float exemplar: `water_passable_[cell] = 1` iff `LandType==Water`. CB-3 uses **binary** passability (matching today's binary `passable_`); speed-% terrain cost is a documented carry-forward `[RE-GATE: naval.md §2]`.
- **Occupancy:** naval units claim `occ_` exactly like ground (one ship per cell). Water and land cells are DISJOINT sets, so naval `occ_` never interacts with ground `occ_` in practice; the shared `occ_` grid and its API are UNCHANGED.
- **Exemplar:** Sea Scorpion `[HYD]` (Soviet, image `HYD`, art PRESENT `hyd.vxl`/`hyd.hva`). Art-guarded; if `HYD` art ever regresses, the guard drops to a present surface ship (`DRED`/`DEST` art verified in the mix) with the demo script adjusted; the naval logic is exemplar-independent and covered by pure tests regardless.
- **Naval combat:** the Sea Scorpion acquires a target and fires `FlakTrackGun` (Damage=25, ROF=25, Range=5) through the EXISTING `commit_attack_target`/`step_combat`/`try_fire` path. Its combat-approach `MoveRequest` routes to a WATER A\* path (the one naval-aware branch in the dispatch). Instant single-target hit (the established projectile simplification, `combat.md`); FlakTProj ballistics deferred. Naval/land targeting permission is `[RE-GATE: naval.md §4]`.
- **Spawn:** CB-3 spawns the exemplar directly (like CB-1/CB-2); no Naval Yard build-from-sidebar.
- **Verification:** new deterministic gate `--demo-naval` (the 11th) + `naval_hash` (FNV over the ship's water-path cells + position + attack state, two-run compute-and-self-compare, NO pinned literal) + wedge guards: the ship must actually MOVE on ≥1 water cell AND be BLOCKED from a land cell AND land ≥1 hit, else exit 1.
- **Byte-identity:** Strategy (a): naval fields excluded from `world_hash`; the Land grid `passable_` kept literally unchanged; every domain-selection site is an added clause provably `Land` for all existing units. Ground-unit A\*, occupancy, and movement stay bit-identical.
- **Decomposition tripwire (spec §2):** the LandType-decoding foundation (Task 2) is net-new `ra2assets` work whose size depends on the §1 item-2 recovery. If Task 2 fans out (a tile-set classification with theater-INI parsing is larger than a per-tile byte), or the pathfinder parameterization touches more sites than the two enumerated (`order_unit_move`, the `step_units` re-path) plus the combat-approach dispatch, the phase splits at the natural seam — **(A) water-movement foundation** (Tasks 1–4, 6; a `--demo-naval-move` gate that only paths a ship across the lake and proves land-blocking, no combat) then **(B) the naval-combat exemplar** (Tasks 5, 7). Default is the single coherent ~8-task phase below.

```cpp
// These byte constants are the Task-1 hunt output (the .tmp TerrainType enum);

namespace {
constexpr std::uint8_t kTmpClear = 0;
constexpr std::uint8_t kTmpRoad  = 1;
constexpr std::uint8_t kTmpWater = 2;
constexpr std::uint8_t kTmpRock  = 3;
constexpr std::uint8_t kTmpBeach = 6;
constexpr std::uint8_t kTmpRough = 7;

        case kTmpRoad:  return LandType::Road;
        case kTmpWater: return LandType::Water;
```

```cpp
// CB-3 Naval [RE-GATE: naval.md §2]: resolve every materialized map cell's
// LandType into a grid_w*grid_h array (indexed y*grid_w + x, the SAME space
// build_water_passability/passable_ use). For each MapCell, resolve its tile's
// TMP via the Theater and read sub-tile `subtile`'s TerrainType byte
// (land_type_of_cell). Cells with no resolvable TMP stay Clear (land, never
// water). Theater::tmp_for_tile is non-const (lazy cache) so `th` is by ref.
std::vector<ra2assets::LandType> resolve_land_types(const ra2assets::MapFile& map,
                                                    ra2engine::Theater& th,
                                                    int grid_w, int grid_h) {
    std::vector<ra2assets::LandType> lt(
        static_cast<std::size_t>(grid_w) * grid_h, ra2assets::LandType::Clear);
    for (const ra2assets::MapCell& c : map.cells()) {
        if (c.x < 0 || c.y < 0 || c.x >= grid_w || c.y >= grid_h) continue;
        const ra2assets::TmpFile* tmp = th.tmp_for_tile(c.tile);
        if (!tmp) continue;                                  // unresolved -> Clear
        if (c.subtile >= static_cast<std::uint8_t>(tmp->count())) continue;
        lt[static_cast<std::size_t>(c.y) * grid_w + c.x] =
            ra2assets::land_type_of_cell(*tmp, c.subtile);
    }
    return lt;
}
```

- Produces — `engine/main.cpp`: `pick_water_cell` (finds the largest 4-connected Water region and returns a start cell + a distant cell in it):

```cpp
// CB-3 Naval [RE: naval.md §2]: pick a start Water cell and a distant Water
// cell in the SAME 4-connected water region, so the demo ship has a real path
// to sail. Returns false if no water region of >= min_cells exists (the Task-1
// Step-6 [RE-FALLBACK] condition -- the caller then errors out visibly).
bool pick_water_cell(const std::vector<ra2assets::LandType>& lt, int gw, int gh,
                     int min_cells, ra2engine::Cellxy& start, ra2engine::Cellxy& far_) {
    const std::size_t n = static_cast<std::size_t>(gw) * gh;
    std::vector<int> comp(n, -1);
    int best_comp = -1, best_size = 0;
    ra2engine::Cellxy best_a{0, 0}, best_b{0, 0};
    for (int y = 0; y < gh; ++y)
        for (int x = 0; x < gw; ++x) {
            const std::size_t i = static_cast<std::size_t>(y) * gw + x;
            if (lt[i] != ra2assets::LandType::Water || comp[i] != -1) continue;
            const int id = static_cast<int>(i);
            std::vector<ra2engine::Cellxy> stack{{x, y}};
            comp[i] = id;
            int size = 0;
            ra2engine::Cellxy a{x, y}, b{x, y};   // extremes for a "distant" pair
            while (!stack.empty()) {
                const ra2engine::Cellxy c = stack.back(); stack.pop_back();
                ++size;
                if (c.x + c.y < a.x + a.y) a = c;
                if (c.x + c.y > b.x + b.y) b = c;
                const int dx[4] = {1, -1, 0, 0}, dy[4] = {0, 0, 1, -1};
                for (int k = 0; k < 4; ++k) {
                    const int nx = c.x + dx[k], ny = c.y + dy[k];
                    if (nx < 0 || ny < 0 || nx >= gw || ny >= gh) continue;
                    const std::size_t j = static_cast<std::size_t>(ny) * gw + nx;
                    if (lt[j] == ra2assets::LandType::Water && comp[j] == -1) {
                        comp[j] = id;
                        stack.push_back({nx, ny});
                    }
                }
            }
            if (size > best_size) { best_size = size; best_comp = id; best_a = a; best_b = b; }
        }
    if (best_comp < 0 || best_size < min_cells) return false;
    start = best_a;
    far_ = best_b;
    return true;
}
```

- Produces — `engine/main.cpp`: `naval_fold` (mirrors `aircraft_fold`; folds the exact state CB-3 adds — every unit's cell/alive/hp + each naval unit's domain/path-size/target + the count of water cells traversed):

```cpp
// FNV fold of the naval-phase state [spec §7]: every unit's (cell_x, cell_y,
// alive, hp) PLUS each naval unit's (movement_domain, path.size(), target) and
// a running count of DISTINCT water cells the ship has occupied. Folded at the
// demo's four fixed checkpoints (post-move, post-land-block, post-attack, end).
// A NEW accumulator; world_hash and every prior *_hash UNTOUCHED.
uint64_t naval_fold(uint64_t h, const ra2engine::World& world, uint64_t water_cells) {
    const std::vector<ra2engine::Unit>& us = world.units();
    for (const ra2engine::Unit& u : us) {
        h = fnv_mix(h, static_cast<uint64_t>(u.cell_x));
        h = fnv_mix(h, static_cast<uint64_t>(u.cell_y));
        h = fnv_mix(h, static_cast<uint64_t>(u.alive ? 1 : 0));
        h = fnv_mix(h, static_cast<uint64_t>(u.hp));
    }
    for (const ra2engine::Unit& u : us) {
        if (!u.is_naval) continue;
        h = fnv_mix(h, static_cast<uint64_t>(static_cast<int>(u.movement_domain)));
        h = fnv_mix(h, static_cast<uint64_t>(u.path.size()));
        h = fnv_mix(h, static_cast<uint64_t>(u.target + 1));
    }
    h = fnv_mix(h, water_cells);
    return h;
}
```

```cpp
                               const std::vector<const VehicleAssets*>& vlist,
                               bool render, SDL_Renderer* ren,
                               ra2engine::TextureCache* tc, const ra2engine::Camera* cam,
                               int W, int H, const std::string& start_png,
                               const std::string& end_png) {
    DemoNavalResult r;
    if (!na.ok) { r.ok = false; return r; }
    ra2engine::World world = build_world(a, ua, 0);
    const int gw = world.grid_w(), gh = world.grid_h();

    // Resolve the map's per-cell LandType and hand World the water grid.
    std::vector<ra2assets::LandType> lt = resolve_land_types(a.map, a.theater, gw, gh);
    world.set_water_terrain(lt);

    // Find a water region: a start cell, a distant cell to sail to, and a firing
    // position between them for the target [RE-GATE: naval.md §2]. If none, this
    // is the Task-1 Step-6 [RE-FALLBACK] -> fail visibly.
    ra2engine::Cellxy w_start{0, 0}, w_far{0, 0};
    if (!pick_water_cell(lt, gw, gh, /*min_cells=*/12, w_start, w_far)) {
        r.ok = false;
        r.witness.emplace_back("[naval] WEDGE: no materialized contiguous water region (RE-FALLBACK)");
        return r;
    }
    // The target sits on a water cell near w_far (in-range of the ship's Range=5
    // once it sails over); use w_far itself as the enemy cell and a cell a few
    // steps in from w_start as the ship's mid-approach goal.
    const ra2engine::Cellxy ship_cell = w_start;
    const ra2engine::Cellxy enemy_cell = w_far;

    world.add_combat_unit(ship_cell.x, ship_cell.y, /*house=*/0, na.va.combat);   // idx 0
    const int s_idx = 0;
    ra2engine::UnitCombat tgt = na.va.combat;    // a second Sea Scorpion (naval duel)
    ra2engine::Unit& enemy = world.add_combat_unit(enemy_cell.x, enemy_cell.y, /*house=*/1, tgt);
    const int t_idx = 1;
    enemy.hp = enemy.max_hp;
    {
        char b[192];
        std::snprintf(b, sizeof b,
                      "[naval] variant=%s ship=(%d,%d) enemy=(%d,%d) range=%.1f",
                      na.id.c_str(), ship_cell.x, ship_cell.y, enemy_cell.x, enemy_cell.y,
                      na.va.combat.range);
        r.witness.emplace_back(b);
    }

    const double dt = 1.0 / 15.0;
    long frame = 0;
    bool moved_on_water = false, land_blocked = false;
    int hits = 0;
    int prev_hp = world.units()[t_idx].hp;
    uint64_t water_cells = 0;
    int last_cx = ship_cell.x, last_cy = ship_cell.y;
    uint64_t h = 0xcbf29ce484222325ull;          // FNV-1a offset basis

    auto is_water = [&](int x, int y) {
        if (x < 0 || y < 0 || x >= gw || y >= gh) return false;
        return lt[static_cast<std::size_t>(y) * gw + x] == ra2assets::LandType::Water;
    };
    auto dead = [&](int i) {
        return !world.units()[i].alive || world.units()[i].die_time >= 0.0;
    };
    auto step_one = [&]() {
        world.step(dt);
        const ra2engine::Unit& s = world.units()[s_idx];
        if ((s.cell_x != last_cx || s.cell_y != last_cy) && is_water(s.cell_x, s.cell_y)) {
            ++water_cells;
            moved_on_water = true;
        }
        last_cx = s.cell_x; last_cy = s.cell_y;
        const int hp = world.units()[t_idx].hp;
        if (hp < prev_hp) ++hits;
        prev_hp = hp;
        ++frame;
        if (render) {
            SDL_SetRenderDrawColor(ren, 10, 20, 60, 255);
            SDL_RenderClear(ren);
            render_world(ren, *tc, a, ua, world, *cam, W, H, nullptr, &vlist);
        }
    };

    // 1) MOVE: sail across the water toward a mid-water cell short of the enemy.
    const int mid_x = (ship_cell.x + enemy_cell.x) / 2;
    const int mid_y = (ship_cell.y + enemy_cell.y) / 2;
    world.order_unit_move(s_idx, mid_x, mid_y);
    if (render) { step_one(); capture_png(ren, start_png, W, H); }
    while (frame < 4000 && world.units()[s_idx].moving()) step_one();
    h = naval_fold(h, world, water_cells);       // checkpoint 1: post-move
    {
        char b[144];
        std::snprintf(b, sizeof b,
                      "[naval] moved cells=%llu path_water=%s arrived=(%d,%d) frame=%ld",
                      static_cast<unsigned long long>(water_cells),
                      moved_on_water ? "yes" : "no",
                      world.units()[s_idx].cell_x, world.units()[s_idx].cell_y, frame);
        r.witness.emplace_back(b);
    }

    // 2) LAND-BLOCK: order the ship to a LAND cell; it must refuse (no water
    //    path -> empty/stay-put), the inverse of a ground unit.
    ra2engine::Cellxy land{0, 0};
    for (int y = 0; y < gh && (land.x == 0 && land.y == 0); ++y)
        for (int x = 0; x < gw; ++x)
            if (!is_water(x, y) &&
                lt[static_cast<std::size_t>(y) * gw + x] == ra2assets::LandType::Clear) {
                land = {x, y}; break;
            }
    const int before_x = world.units()[s_idx].cell_x, before_y = world.units()[s_idx].cell_y;
    world.order_unit_move(s_idx, land.x, land.y);
    const bool empty_path = world.units()[s_idx].path.empty();
    for (int f = 0; f < 60; ++f) step_one();
    if (empty_path && world.units()[s_idx].cell_x == before_x &&
        world.units()[s_idx].cell_y == before_y)
        land_blocked = true;
    h = naval_fold(h, world, water_cells);       // checkpoint 2: post-land-block
    {
        char b[144];
        std::snprintf(b, sizeof b, "[naval] land-block ordered=(%d,%d) moved=%s frame=%ld",
                      land.x, land.y, land_blocked ? "no" : "YES-BUG", frame);
        r.witness.emplace_back(b);
    }

    // 3) ATTACK: order the ship to attack the hostile ship; it approaches over
    //    water (the combat-approach naval branch) and fires FlakTrackGun.
    world.clear_selection();
    world.units()[s_idx].selected = true;
    world.order_attack(t_idx);
    while (frame < 9000 && !dead(t_idx)) step_one();
    h = naval_fold(h, world, water_cells);       // checkpoint 3: post-attack
    {
        char b[144];
        std::snprintf(b, sizeof b, "[naval] hit target=%d dmg-events=%d target_dead=%s frame=%ld",
                      t_idx, hits, dead(t_idx) ? "yes" : "no", frame);
        r.witness.emplace_back(b);
    }

    // 4) RESUME: fixed window; the ship holds station on the water.
    const long resume_until = frame + 150;
    while (frame < resume_until) step_one();
    h = naval_fold(h, world, water_cells);       // checkpoint 4: end
    r.hash = h;

    {
        char b[176];
        std::snprintf(b, sizeof b,
                      "[naval] final moved_on_water=%s land_blocked=%s hits=%d water_cells=%llu frame=%ld",
                      moved_on_water ? "yes" : "no", land_blocked ? "yes" : "no", hits,
                      static_cast<unsigned long long>(water_cells), frame);
        r.witness.emplace_back(b);
    }
    char hb[64];
    std::snprintf(hb, sizeof hb, "[naval] naval_hash=%016llx",
                  static_cast<unsigned long long>(r.hash));
    r.witness.emplace_back(hb);

    // Wedge guards [spec §7]: the gate can never pass vacuously -- the ship must
    // MOVE on >=1 water cell AND be BLOCKED from a land cell AND land >=1 hit.
    if (!moved_on_water) { r.ok = false; r.witness.emplace_back("[naval] WEDGE: no move on water"); }
    if (!land_blocked) { r.ok = false; r.witness.emplace_back("[naval] WEDGE: not blocked from land"); }
    if (hits < 1) { r.ok = false; r.witness.emplace_back("[naval] WEDGE: no hit landed on the target"); }
    if (render) { capture_png(ren, end_png, W, H); }   // capture the ALREADY-rendered frame
    return r;
}
```
