# Shroud / Fog-of-War Phase Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add RA2's shroud / fog-of-war visibility layer — a per-house three-state cell model (SHROUDED / FOGGED / VISIBLE) where a house's own units and buildings reveal a near-circular `Sight`-radius, explored terrain stays visible-but-dimmed and never re-shrouds by tick (shipped `FogOfWar=no`), the enemy auto-acquire scan skips objects it cannot currently see, and the two confirmed reveal-events (own SpySat → reveal whole map; spy infiltrating an enemy radar → re-shroud the victim, wiring the Capture phase's inert `InfiltratePurpose::RadarLab`) — demonstrated deterministically and guarded by the **15th permanent byte-identity gate `--demo-shroud`** (`shroud_hash`). The 14 existing gates stay bit-identical.

**Architecture:** Task 1 adjudicates the RE-GATE (the hunt `docs/re/shroud.md` is COMPLETE — Task 1 re-pins the Sight values via `ra2extract` and closes the three [RE-FALLBACK] items, NOT a fresh hunt). Visibility is a **per-house** layer (D1): two independent grids per house (`explored_[3]` sticky fog, `visible_[3]` recomputed each tick), EMPTY until `shroud_any_` opens them, indexed `y*grid_w_+x` exactly like `passable_`/`water_passable_`. A new firewalled `World::step_visibility()` pass runs **after `step_units`** and **before `step_combat`**, opening `if (!shroud_any_) return;` (the `step_capture` precedent) — a strict no-op in every existing gate. Targeting consults a per-unit `seen_by_mask` (default `0xFF` = seen-by-all = INERT) via ONE extra clause at `combat.cpp:362` mirroring the existing `|| units[j].disguised`. Rendering (house 0) and the greenfield radar minimap consult the grids; with shroud off the accessors return all-visible so the render is pixel-identical. Task 7 wires the spy/radar reveal effects (resolving the Capture-phase INERT item). `world_hash` and `combat.cpp`'s scan body arithmetic are **NOT touched**; the new state is hashed ONLY by `shroud_hash`.

**Tech Stack:** C++17, doctest, CMake+Ninja (desktop `build/`, Android `android/` gradle, NDK `D:\android-ndk-r27c`, JDK-21), Ghidra headless (`analyzeHeadless.bat`, `JAVA_HOME=C:\Program Files\Java\jdk-21`, project `D:\ra2-re`) for the confirmatory RE-GATE only, SDL2 (render/UI layer), `ra2assets::Rules`/`ra2assets::Ini` as the rulesmd substrate, a new pure `engine/visibility.{hpp,cpp}` module (near-circular reveal math, host-doctestable), reusing `engine/world.cpp`'s firewall/step-pass pattern (`step_capture`/`capture_any_`), the `passable_`/`water_passable_` grid shape, `engine/iso_renderer.cpp`'s `draw_terrain`/`cell_to_screen`/`pal_for_house`, `main.cpp`'s `shade_rect`/`render_world`/sidebar radar box, and the `run_demo_capture`/`capture_fold` gate template.

// Shroud/Fog phase [RE: shroud.md §3]: pure near-circular reveal math, shared by
// World::reveal_source and host-doctestable without a World. No SDL/World/RNG.
#include <cstdint>
#include <vector>

namespace ra2engine {

// Near-circular membership [RE-GATE APPLIED: shroud.md §3 -- dx2+dy2<=sight2,
// integer cell centers, inclusive boundary]. sight is in whole cells (clamped
// to 10 at data-load). sight <= 0 -> only the source cell (dx=dy=0) qualifies.
inline bool cell_in_sight(int dx, int dy, int sight) {
    return dx * dx + dy * dy <= sight * sight;
}

// Stamp a near-circular disc of radius `sight` cells around (cx,cy) into two

#include "visibility.hpp"

namespace ra2engine {

int reveal_disc(std::vector<std::uint8_t>& explored,
                std::vector<std::uint8_t>& visible,
                int gw, int gh, int cx, int cy, int sight) {
    if (gw <= 0 || gh <= 0) return 0;
    if ((int)explored.size() != gw * gh || (int)visible.size() != gw * gh) return 0;
    const int r = sight < 0 ? 0 : sight;   // negative sight -> source cell only
    int n = 0;
    for (int dy = -r; dy <= r; ++dy) {
        const int y = cy + dy;
        if (y < 0 || y >= gh) continue;
        for (int dx = -r; dx <= r; ++dx) {
            const int x = cx + dx;
            if (x < 0 || x >= gw) continue;
            if (!cell_in_sight(dx, dy, r)) continue;   // near-circular filter
            const int idx = y * gw + x;
            visible[idx] = 1;
            explored[idx] = 1;   // sticky
            ++n;
        }
    }
    return n;
}

}  // namespace ra2engine

void World::enable_shroud(bool on) {
    shroud_any_ = on;
    for (int h = 0; h < 3; ++h) {
        if (on) {
            explored_[h].assign((size_t)grid_w_ * grid_h_, 0);
            visible_[h].assign((size_t)grid_w_ * grid_h_, 0);
        } else {
            explored_[h].clear();
            visible_[h].clear();
        }
    }
}

bool World::visible_at(int house, int x, int y) const {
    if (house < 0 || house >= 3) return true;             // inert
    if (visible_[house].empty()) return true;             // shroud off -> all-visible
    if (x < 0 || y < 0 || x >= grid_w_ || y >= grid_h_) return false;
    return visible_[house][(size_t)y * grid_w_ + x] != 0;
}

bool World::explored_at(int house, int x, int y) const {
    if (house < 0 || house >= 3) return true;             // inert
    if (explored_[house].empty()) return true;            // shroud off -> all-explored
    if (x < 0 || y < 0 || x >= grid_w_ || y >= grid_h_) return false;
    return explored_[house][(size_t)y * grid_w_ + x] != 0;
}

void World::reveal_source(int house, int cx, int cy, int sight) {
    if (house < 0 || house >= 3 || visible_[house].empty()) return;
    reveal_disc(explored_[house], visible_[house], grid_w_, grid_h_, cx, cy, sight);
}

void World::step_visibility() {
    if (!shroud_any_) return;                             // firewall (spec §Global)
    // 1) Clear visible_ (explored_ is sticky -- fog no-regrow §4).
    for (int h = 0; h < 3; ++h)
        if (!visible_[h].empty())
            std::fill(visible_[h].begin(), visible_[h].end(), (std::uint8_t)0);
    // 2) Reveal from every ALIVE unit (near-circular, radius = its sight).
    for (const Unit& u : units_) {
        if (!u.alive) continue;
        reveal_source(u.house, u.cell_x, u.cell_y, u.sight);
    }
    // 3) Reveal from every ALIVE building, ONCE PER FOOTPRINT CELL (§3).
    for (const Building& b : buildings_) {
        if (!b.alive || b.state == Building::State::Dead) continue;
        for (int fy = 0; fy < b.fh; ++fy)
            for (int fx = 0; fx < b.fw; ++fx)
                reveal_source(b.house, b.cx + fx, b.cy + fy, b.sight);
    }
    // 4) Stamp each unit's seen_by_mask: bit h set iff its cell is visible_ to h.
    for (Unit& u : units_) {
        if (!u.alive) continue;
        std::uint8_t m = 0;
        for (int h = 0; h < 3; ++h)
            if (visible_at(h, u.cell_x, u.cell_y)) m |= (std::uint8_t)(1u << h);
        u.seen_by_mask = m;
    }
}
