# AI-1 Base-Planning Phase Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Non-player houses get a base-planning brain (sub-phase AI-1 of the three-sub-phase AI effort). The enemy Soviet house — which today owns a pre-built base and a working economy but never acts — gains a planner that decides what to build next (recovered topologically prereq-sorted base-node plan [RE-GATE APPLIED: ai-base.md §2/§2a]), where to place it (recovered placement scan — AI bypasses `Adjacent=` [RE-GATE APPLIED: ai-base.md §3]), and rebuilds what it loses, driving the EXISTING production queues, placement validity, and building-placed path. Verified by a new 6th permanent byte-identity gate `--demo-ai-base`.

**Architecture:** Task 1 recovers ground truth from gamemd.exe + rulesmd `[AI]`/difficulty sections into `docs/re/ai-base.md`; then the change lands additively, protecting all five byte-identity gates. A new pure module `engine/ai_base.{hpp,cpp}` holds the brain as free functions (`build_base_plan`, `next_build`, `find_build_location`, `difficulty_mods`) over a read-only `BaseView` plus a small per-house `AiBaseState`; `engine/world.{hpp,cpp}` gains a per-house AI registry and `step_ai_houses()` (early-return firewall when no house is AI-flagged) that drives the EXISTING `ProductionQueues::start` / `placement_check` / `add_building` machinery — NO new production or placement code; `main.cpp` flags house 1 AI in the interactive path, expands the Soviet roster art, and wires the `--demo-ai-base` gate. Spec: `docs/superpowers/specs/2026-07-12-ai-base-design.md`.

    // row-major order as the stable tie-break. BaseBias is NOT used here —
    // it is a threat-TARGETING multiplier [RE: ai-base.md §2].]
    const int ox = view.center_x, oy = view.center_y;

                ring.push_back(Cellxy{ox + dx, oy + dy});

        if (is_defense) {
            std::stable_sort(ring.begin(), ring.end(), [&](const Cellxy& a, const Cellxy& b) {

                       dist2(b.x, b.y, view.threat_x, view.threat_y);

// negative token expands to (-1 Power/BuildPower, -2 Factory/BuildWeapons,
// -3 Barracks/BuildBarracks, -4 Radar/BuildRadar, -5 Tech/BuildTech,
// -6 PROC/BuildRefinery — ai-base.md §2a Evidence 1, so the AiCatalog IS
// the recovered group table). An unresolvable token (catalog gap, TECH in
// AI-1) is UNMET — the cycle-breaker below eventually force-emits.]
bool prereqs_in_plan(int type, const std::vector<PlannedNode>& plan,
                     const std::vector<BuildingTypeDef>& roster,
                     const AiCatalog& cat) {
    for (const std::string& tok : roster[type].prerequisite) {
        int want = -1;  // roster index a group token demands; -1 = plain token
        if (tok == "POWER") want = cat.power;
        else if (tok == "FACTORY") want = cat.war_factory;
        else if (tok == "BARRACKS") want = cat.barracks;
        else if (tok == "RADAR") want = cat.radar;
        else if (tok == "PROC") want = cat.refinery;
        bool met = false;
        for (const PlannedNode& n : plan) {
            if (n.type < 0) continue;
            if (want >= 0 ? n.type == want : roster[n.type].id == tok) {
                met = true;
                break;
            }
        }
        if (!met) return false;
    }
    return true;
}
}  // namespace

std::vector<PlannedNode> build_base_plan(const BaseView& view, const AiCatalog& cat,
                                         const std::vector<BuildingTypeDef>& roster,
                                         const AiRules& ai, const DifficultyMods& mods) {
    // [RE-GATE APPLIED: ai-base.md §2a — FUN_005052d0 is a Kahn-style
    // TOPOLOGICAL PREREQ-SORT, not a fixed-order append. ConYard + Power
    // are appended directly (§2 steps 1-2); Barracks/War Factory are
    // HOISTED to candidate indices 0/1 as a PREFERENCE ONLY (§2 steps 3-4)
    // — the sort OVERRIDES the hoist when a prereq is unmet, which is
    // exactly how the Refinery (needs only Power) lands BEFORE the War
    // Factory (needs PROC) and the Radar (needs NAREFN). A catalog gap
    // (-1: art missing / not in this install) is SKIPPED — art-guard-drop,
    // never a crash. `view` stays reserved for later sub-phases.]
    (void)view;
    std::vector<PlannedNode> plan;
    int next_id = 0;  // contiguous ids 0..N-1 for the static plan; next_build
                      // continues the per-state counter past the max (below)
    auto append = [&](int t) {
        PlannedNode n;
        n.id = next_id++;
        n.type = t;
        plan.push_back(n);
    };
    // 1-2) ConYard + Power append DIRECTLY (not topo-gated) [RE: §2].
    if (cat.conyard >= 0 && cat.conyard < (int)roster.size()) append(cat.conyard);
    if (cat.power >= 0 && cat.power < (int)roster.size()) append(cat.power);
    // 3-4) Candidate multiset in PREFERENCE order: Barracks + War Factory
    // hoisted to the front [RE: §2 steps 3-4], then the prereq-sorted
    // remainder (AI-1: radar), Refineries x RefineryLimit(4), defenses x
    // per-difficulty count (cycling the side list deterministically —
    // stands in for the AIForcePrediction weighting [RE-FALLBACK: ai-base.md
    // §2]), walls (ConcreteWalls) at the natural tail — wall cells resolve
    // at placement from the defense foundation perimeter (FUN_0050c160)
    // [RE: §2/§3; RE-FALLBACK: one perimeter node per defense in AI-1].
    std::vector<int> cand;
    auto add_cand = [&](int t) {
        if (t >= 0 && t < (int)roster.size()) cand.push_back(t);
    };
    add_cand(cat.barracks);
    add_cand(cat.war_factory);
    add_cand(cat.radar);
    for (int i = 0; i < ai.refinery_limit; ++i) add_cand(cat.refinery);
    const int defs = std::min(mods.defense_target, ai.defense_limit);
    if (!cat.defenses.empty())
        for (int i = 0; i < defs; ++i)
            add_cand(cat.defenses[i % (int)cat.defenses.size()]);
    if (cat.wall >= 0 && !cat.defenses.empty())
        for (int i = 0; i < defs; ++i) add_cand(cat.wall);
    // 5) Kahn-style topological loop [RE-GATE APPLIED: ai-base.md §2a —
    // FUN_005052d0's main loop]: emit the FIRST candidate whose prereqs are
    // already met BY THE PLAN-SO-FAR (prereqs_in_plan == the original's
    // FUN_00505180 fed &outputPlanVector), then rescan from the front so
    // the hoisted candidates are always retried first. Deterministic — no
    // RNG: extra refineries fall in right after the prereq-sorted core
    // instead of the original's RNG-spaced inserts, and defenses stay
    // consecutive [RE-FALLBACK: ai-base.md deviations — engine-deterministic
    // stand-in for the lockstep-RNG positions].
    while (!cand.empty()) {
        bool progress = false;
        for (std::size_t i = 0; i < cand.size(); ++i) {
            if (!prereqs_in_plan(cand[i], plan, roster, cat)) continue;
            append(cand[i]);
            cand.erase(cand.begin() + i);
            progress = true;
            break;  // rescan from the front: the hoist preference
        }
        if (!progress) {
            // FORCE-EMIT cycle-breaker [RE-GATE APPLIED: ai-base.md §2a —
            // the !progress branch force-appends an unused candidate so the
            // loop ALWAYS terminates, even on an unsatisfiable/cyclic
            // prereq set; matching FUN_005052d0, the LAST unused candidate
            // is taken — deterministic, no RNG].
            append(cand.back());
            cand.pop_back();
        }
    }
    // NOTE: the static plan is NOT trimmed by BaseSizeAdd — the cap gates
    // DYNAMIC expansion (next_build) at rival + BaseSizeAdd(3) [RE: §2].
    return plan;
}

BuildDecision next_build(AiBaseState& state, const BaseView& view,
                         const AiCatalog& cat,
                         const std::vector<BuildingTypeDef>& roster,
                         const AiRules& ai, const DifficultyMods& mods) {
    // Lazy plan build — the original builds the node vector iff empty
    // (FUN_0050a3e0 -> FUN_005052d0) [RE: ai-base.md §2/§3].
    if (state.plan.empty()) {
        state.plan = build_base_plan(view, cat, roster, ai, mods);
        // Continue the stable-id counter past the ids build_base_plan
        // assigned so every later insert/append draws a fresh id.
        state.next_node_id = 0;
        for (const PlannedNode& n : state.plan)
            if (n.id + 1 > state.next_node_id) state.next_node_id = n.id + 1;
    }

    // PLAN WALK [RE-GATE APPLIED: ai-base.md §1/§2/§2a/§5 — FUN_004fe200
    // is a HEAD-ONLY dispatcher]: the first UNSATISFIED node in plan order,
    // ONE structure at a time (the single Structure-queue slot /
    // house+0x564c gate lives with the caller). Satisfaction is
    // existence-based: each node is covered by one standing own building of
    // its type; a DEAD node is unsatisfied again at its ORIGINAL position
    // -> rebuild-before-tail-expansion [RE: §5]. The walk NEVER skips a
    // prereq-blocked head and has NO find-next-buildable scan —
    // FUN_004fe200 peeks the head node only; the topologically
    // prereq-sorted plan (build_base_plan) guarantees the head is buildable
    // once its predecessors stand [RE: §2a]. The ONLY thing ever put ahead
    // of the head is the power-preemption INSERT below.
    std::vector<int> claimed(roster.size(), 0);
    for (int i = 0; i < (int)state.plan.size(); ++i) {
        const PlannedNode& n = state.plan[i];
        if (n.type < 0 || n.type >= (int)roster.size()) continue;  // gap/marker
        if (!n.dead && claimed[n.type] < count_alive(view, n.type)) {
            ++claimed[n.type];  // satisfied by a standing building
            continue;
        }
        // POWER PREEMPTION [RE-GATE APPLIED: ai-base.md §1/§2 —
        // FUN_004fe200 step 4]: before a drainer that would push
        // drain > output - PowerSurplus(50), INSERT a Power node ahead of
        // it. PowerSurplus (the reserve), this gate, and
        // PowerEmergency=0.75 (a SELL trigger — recorded in kAiPowerEmergency,
        // NOT consumed by AI-1) are THREE DISTINCT rules [RE: §2].
        const BuildingTypeDef& t = roster[n.type];
        if (t.power < 0 && cat.power >= 0 && n.type != cat.power &&
            view.power_drain + (-t.power) >
                view.power_output - (int)ai.power_surplus) {
            PlannedNode p;
            p.id = state.next_node_id++;  // stable id -> pending[] never aliases
            p.type = cat.power;
            state.plan.insert(state.plan.begin() + i, p);
            return pick_node(state.plan, i, view, roster, ai, mods);
        }
        return pick_node(state.plan, i, view, roster, ai, mods);
    }

    // ECONOMY EXPANSION [RE-GATE APPLIED: ai-base.md §2 — FUN_004fdb30]: a
    // SEPARATE trigger once the plan is satisfied — APPEND an extra
    // refinery (then war-factory) node when under its Ratio/Limit and
    // affordable. Opportunistic: unaffordable -> no wait, just bank.
    // BaseSizeAdd caps the whole base at rival + BaseSizeAdd(3) [RE: §2].
    if ((int)view.own.size() >= view.rival_base_size + ai.base_size_add)
        return BuildDecision{};  // base big enough: build nothing
    const int expand[2] = {cat.refinery, cat.war_factory};
    const int limit[2] = {ai.refinery_limit, ai.war_limit};
    for (int e = 0; e < 2; ++e) {
        const int t = expand[e];
        if (t < 0 || count_alive(view, t) >= limit[e]) continue;
        if (view.credits < roster[t].cost * mods.cost_mul + ai.credit_reserve)
            continue;  // opportunistic — no wait
        PlannedNode n;
        n.id = state.next_node_id++;  // stable id for the appended expansion node
        n.type = t;
        state.plan.push_back(n);
        BuildDecision d;
        d.type = t;
        d.node = (int)state.plan.size() - 1;
        return d;
    }
    return BuildDecision{};  // plan satisfied, limits met: build nothing
}

BaseView World::make_ai_base_view(int house, const HouseAiRec& rec) const {
    BaseView v;
    bool conyard_center = false;  // a ConYard's cell locked the center
    bool any_center = false;      // some building set a provisional center
    long long tx = 0, ty = 0, tn = 0;
    std::vector<int> rival_counts;  // per-house alive-building counts (rivals)
    for (const Building& b : buildings_) {
        if (!b.alive || b.state == Building::State::Dead) continue;
        if (b.house == house) {
            BaseBuildingView bb;
            bb.type = b.type;
            bb.cx = b.cx; bb.cy = b.cy; bb.fw = b.fw; bb.fh = b.fh;
            bb.operational = b.state == Building::State::Idle;
            v.own.push_back(bb);
            // Base center = the FIRST ConYard's origin cell; if the house
            // owns none (yet), the FIRST building stands in.
            const bool is_cy = b.type >= 0 && b.type < (int)rec.cfg.roster.size() &&
                               rec.cfg.roster[b.type].conyard;
            if (is_cy && !conyard_center) {
                v.center_x = b.cx; v.center_y = b.cy;
                conyard_center = true;
            } else if (!conyard_center && !any_center) {
                v.center_x = b.cx; v.center_y = b.cy;
                any_center = true;
            }
        } else {
            tx += b.cx; ty += b.cy; ++tn;  // threat = other houses' centroid
            // rival_base_size = largest OTHER house's building count — the
            // BaseSizeAdd cap basis (AI base <= rival + 3) [RE: ai-base.md §2].
            if ((int)rival_counts.size() <= b.house) rival_counts.resize(b.house + 1, 0);
            v.rival_base_size = std::max(v.rival_base_size, ++rival_counts[b.house]);
        }
    }
    if (tn > 0) { v.threat_x = (int)(tx / tn); v.threat_y = (int)(ty / tn); }
    else { v.threat_x = grid_w_ / 2; v.threat_y = grid_h_ / 2; }
    v.credits = rec.credits;
    const PowerTotals pt = power_totals(buildings_, rec.cfg.roster, house);
    v.power_output = pt.output;
    v.power_drain = pt.drain;
    for (const Unit& u : units_)
        if (u.alive && u.house == house && u.is_harvester) ++v.harvesters;
    return v;
}

// Places queue `cat`'s READY building at its planned node's cell through the
// EXISTING validity + add_building path [RE: ai-base.md §3/§6]. Returns true
// if the slot was consumed (placed); false = HOLD (retry next frame).
bool World::ai_place_ready(int house, HouseAiRec& rec, QueueCat cat) {
    const int q = cat == QueueCat::Structure ? 0 : 1;
    if (!rec.queues.ready(cat)) return false;
    const int node_i = rec.state.pending[q];
    if (node_i < 0 || node_i >= (int)rec.state.plan.size()) {
        rec.queues.placed(cat);  // defensive: orphaned ready slot
        rec.state.pending[q] = -1;
        return true;
    }
    PlannedNode& node = rec.state.plan[node_i];
    const BuildingTypeDef& t = rec.cfg.roster[node.type];
    auto can_place = [&](int cx, int cy) {
        // AI validity [RE-GATE APPLIED: ai-base.md §3]: the AI BYPASSES the
        // Adjacent= proximity check (FUN_004a8dc0 early-returns for
        // non-local-human houses) -> bypass_adjacency=true; the shared
        // per-cell buildable/unoccupied grid still applies, probed over the
        // foundation expanded by the AIBaseSpacing(1) gap [RE-FALLBACK: gap
        // modeled as an expanded-foundation probe].
        const int s = rec.cfg.ai.base_spacing;
        return placement_check(cx - s, cy - s, t.fw + 2 * s, t.fh + 2 * s,
                               house, t.adjacent, passable_,
                               grid_w_, grid_h_, occ_, buildings_,
                               /*bypass_adjacency=*/true).ok;
    };
    int px = node.cx, py = node.cy;
    if (!can_place(px, py)) {
        // Something moved onto the node's cell: re-scan (deterministic).
        const BaseView v = make_ai_base_view(house, rec);
        const bool is_def = std::find(rec.cfg.catalog.defenses.begin(),
                                      rec.cfg.catalog.defenses.end(),
                                      node.type) != rec.cfg.catalog.defenses.end();
        const Cellxy alt = find_build_location(v, is_def, can_place);
        if (alt.x < 0) return false;  // boxed in -> HOLD the ready slot
        px = alt.x; py = alt.y;
        node.cx = px; node.cy = py;
    }
    const double buildup = node.type < (int)rec.cfg.buildup_totals.size()
                               ? rec.cfg.buildup_totals[node.type] : 0.0;
    const int idx = add_building(node.type, px, py, t.fw, t.fh, house, t.strength,
                                 t.armor_ix, buildup, /*instant=*/false);
    node.building = idx;
    node.dead = false;
    rec.queues.placed(cat);
    rec.state.pending[q] = -1;
    return true;
}

void World::step_ai_houses(double dt) {
    for (int h = 0; h < (int)ai_houses_.size(); ++h) {
        HouseAiRec& rec = ai_houses_[h];
        if (!rec.is_ai) continue;
        const AiHouseConfig& cfg = rec.cfg;

        // 1) Income (the economy phase accumulates per-house unload income).
        rec.credits += take_income(h);

        // 2) Node-death detection [RE: ai-base.md §5].
        for (PlannedNode& n : rec.state.plan) {
            if (n.building < 0) continue;
            const Building& b = buildings_[n.building];
            if (!b.alive || b.state == Building::State::Dead) {
                n.building = -1;
                n.dead = true;
            }
        }

        // 3) ConYard-lost cancels both building queues (the same rule the
        //    player's prod_tick applies) [RE: ai-base.md §6].
        bool conyard = false;
        for (const Building& b : buildings_) {
            if (b.alive && b.state == Building::State::Idle && b.house == h &&
                b.type >= 0 && b.type < (int)cfg.roster.size() &&
                cfg.roster[b.type].conyard) { conyard = true; break; }
        }
        if (!conyard) {
            for (QueueCat c : {QueueCat::Structure, QueueCat::Defense})
                if (rec.queues.producing(c) != -1) rec.queues.cancel(c);
        }

        // 4) Tick the queues: SAME power clamp as the player [RE: ai-base.md
        //    §6], difficulty time handicap applied at start() (below).
        const PowerTotals pt = power_totals(buildings_, cfg.roster, h);
        const double pmul = build_speed_multiplier(pt, cfg.low_power_penalty);
        rec.queues.set_credits(rec.credits);
        const double sp[4] = {1.0, 1.0, 1.0, 1.0};  // one ConYard in AI-1 — no
                                                    // MultipleFactory speedup
        rec.queues.tick(dt, pmul, sp, cfg.roster);
        rec.credits = rec.queues.credits();

        // 5) Place READY slots (Structure then Defense — deterministic order).
        ai_place_ready(h, rec, QueueCat::Structure);
        ai_place_ready(h, rec, QueueCat::Defense);

        // 6) Build clock [RE-GATE APPLIED: ai-base.md §1 — two timers stack
        //    in the original: the AI tick SELF-RESCHEDULES 0x69 + rand(1,7)
        //    = 105–112 frames (~7 s at 15 Hz), and the per-house BuildDelay
        //    timer is seeded from the difficulty BuildDelay MINUTES
        //    [RE-FALLBACK: secs = min x 60]. The jitter draw uses the
        //    engine-local xorshift32 [RE-FALLBACK: ai-base.md deviations —
        //    stands in for the lockstep game RNG; NEVER wall-clock].
        rec.state.build_clock += dt;
        if (rec.state.build_clock < rec.state.build_gate) continue;
        rec.state.build_clock = 0.0;
        rec.state.build_gate = std::max(
            (double)(0x69 + 1 + (int)(ai_rand(rec.state.rng) % 7)) / 15.0,
            cfg.mods.build_delay_min * 60.0);
        if (!conyard) continue;  // no factory: nothing can start

        // 7) Decide.
        const BaseView view = make_ai_base_view(h, rec);
        const BuildDecision d =
            next_build(rec.state, view, cfg.catalog, cfg.roster, cfg.ai, cfg.mods);
        if (d.type < 0) continue;  // nothing needed, or wait/bank

        // 8) Route to the queue the player would use [RE: ai-base.md §6]:
        //    defenses -> Defense queue, everything else -> Structure queue.
        const bool is_def = std::find(cfg.catalog.defenses.begin(),
                                      cfg.catalog.defenses.end(),
                                      d.type) != cfg.catalog.defenses.end();
        const QueueCat cat = is_def ? QueueCat::Defense : QueueCat::Structure;
        const int q = is_def ? 1 : 0;
        if (rec.queues.producing(cat) != -1 || rec.state.pending[q] != -1)
            continue;  // slot busy — the single-slot queue IS the recovered
                       // one-AI-structure-at-a-time gate (house+0x564c stays
                       // set until placement) [RE-GATE APPLIED: ai-base.md §1]

        // 9) Same prereq/tech/factory gate as the player (can_start —
        //    EXISTING function) [RE: ai-base.md §6].
        if (!can_start(rec.queues.state(cat), d.type, cfg.roster, buildings_, h,
                       cfg.groups, conyard))
            continue;

        // 10) The decision names its plan node [RE-GATE APPLIED: ai-base.md
        //     §3/§5 — every start fills a node of the ordered plan; next_build
        //     already inserted/appended override nodes]. A REBUILD node keeps
        //     its stored cell (re-validated by ai_place_ready); a FRESH node
        //     ((0,0) = cell not yet chosen, the original's node+4 == 0) gets
        //     its cell from the deterministic scan NOW and stores it.
        const int node_i = d.node;
        PlannedNode& pn = rec.state.plan[node_i];
        if (!pn.dead && pn.cx == 0 && pn.cy == 0) {
            const BuildingTypeDef& t = cfg.roster[d.type];
            auto can_place = [&](int cx, int cy) {
                // Same AI validity as ai_place_ready: Adjacent= BYPASSED +
                // AIBaseSpacing(1) gap [RE-GATE APPLIED: ai-base.md §3].
                const int s = cfg.ai.base_spacing;
                return placement_check(cx - s, cy - s, t.fw + 2 * s, t.fh + 2 * s,
                                       h, t.adjacent, passable_,
                                       grid_w_, grid_h_, occ_, buildings_,
                                       /*bypass_adjacency=*/true).ok;
            };
            const Cellxy loc = find_build_location(view, is_def, can_place);
            if (loc.x < 0) continue;  // boxed in: try again next clock
            pn.cx = loc.x; pn.cy = loc.y;
        }

        // 11) START on the EXISTING queue economy: difficulty cost handicap
        //     on the charge, BuildTime handicap on the speed (Easy 0.8 =
        //     faster; Normal/Difficult 1.0) [RE: ai-base.md §4].
        //     (cfg.mods.build_slowdown is recorded but not consumed in AI-1
        //     — it lands with the unit-production AI sub-phase.)
        const BuildingTypeDef& t = cfg.roster[d.type];
        const int basis = t.charge > 0 ? t.charge : t.cost;
        const int ai_charge =
            std::max(1, (int)(basis * cfg.mods.cost_mul));
        rec.queues.set_credits(rec.credits);
        start(rec.queues.state(cat), t.cost, ai_charge,
              cfg.build_speed * cfg.mods.build_time_mul);
        rec.queues.state(cat).slot.type = d.type;
        rec.credits = rec.queues.credits();
        rec.state.pending[q] = node_i;
    }
}

// FNV hash of the AI-1 end state for --demo-ai-base's two-run byte-identity
// gate [RE: ai-base.md]: the SORTED alive-building list [type, cell, hp] +
// credits + power totals + the planned-node list. A NEW function; world_hash
// / econ_hash / prod_hash UNTOUCHED.
uint64_t ai_base_hash(const ra2engine::World& world, int house,
                      const std::vector<ra2engine::BuildingTypeDef>& roster) {
    uint64_t h = 1469598103934665603ULL;  // FNV offset basis
    std::vector<std::array<int, 4>> rows;
    for (const ra2engine::Building& b : world.buildings()) {
        if (!b.alive || b.house != house) continue;
        rows.push_back({b.type, b.cx, b.cy, b.hp});
    }
    std::sort(rows.begin(), rows.end());
    for (const auto& r : rows)
        for (int x : r) h = fnv_mix(h, static_cast<uint64_t>(x));
    h = fnv_mix(h, static_cast<uint64_t>(std::llround(world.ai_credits(house))));
    const ra2engine::PowerTotals pt =
        ra2engine::power_totals(world.buildings(), roster, house);
    h = fnv_mix(h, static_cast<uint64_t>(pt.output));
    h = fnv_mix(h, static_cast<uint64_t>(pt.drain));
    if (const ra2engine::AiBaseState* st = world.ai_state(house)) {
        for (const ra2engine::PlannedNode& n : st->plan) {
            h = fnv_mix(h, static_cast<uint64_t>(n.type));
            h = fnv_mix(h, static_cast<uint64_t>(n.cx));
            h = fnv_mix(h, static_cast<uint64_t>(n.cy));
            h = fnv_mix(h, static_cast<uint64_t>(n.dead ? 1 : 0));
            h = fnv_mix(h, static_cast<uint64_t>(n.building >= 0 ? 1 : 0));
        }
    }
    return h;
}
