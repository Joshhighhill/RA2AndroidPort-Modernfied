**Goal:** Add a **FLIGHT** movement mode to the from-scratch RA2 engine — a unit travels in a straight line at a cruise **altitude** ignoring ground pathing / terrain-walkability / cell-occupancy (flies over everything, reserves no ground cell while airborne), turns its facing toward travel, **takes off** and **descends**, is drawn **raised** on screen with a **ground shadow**, and **acquires and attacks a ground target from the air** composing on the existing combat path — demonstrated deterministically on the real Kirov Airship (`[ZEP]`, art `ZEP`) and gated by the **10th permanent byte-identity gate `--demo-aircraft`**. **Architecture:** Task 1 recovers ground truth from gamemd.exe (YR 1.001) + the real rulesmd/artmd into `docs/re/aircraft.md` (RE-GATE before any dependent code). Then the change lands additively into the CORE unit sim — it cannot hide behind the `ai_any_` firewall, so the byte-identity discipline (spec §8) is itself a deliverable: a new pure module `engine/flight.{hpp,cpp}` holds `step_altitude` (climb/descend integrate to bound, no overshoot), `cruise_step` (straight-line advance, never touches `passable_`/`occ_`), `heading_toward` (shortest-arc turn, no-turn on OmniFire), `altitude_to_screen_dy` (the §5 raised-draw offset), and `advance_flight_state` (the `Grounded/TakingOff/Cruising/Descending` transitions). `engine/world.{hpp,cpp}` grows inert-by-default `Unit`/`UnitCombat` flight fields, an aircraft branch in `order_unit_move` (flight goal, NOT A*), a new `step_flight` pass inserted between `step_cargo` and `step_turrets` behind an `aircraft_any_` firewall bool, the airborne no-occupancy behavior, and the `|| u.is_aircraft` / `&& !v.is_aircraft` guard clauses grown onto EXISTING corpse/target-skip conditions (provably false / negation provably true in every existing demo). `engine/combat.cpp` grows one `!u.omni_fire` clause on the vehicle aim gate (fire-from-cruise for the turretless OmniFire flyer). `engine/main.cpp` resolves the `[ZEP]` flight stats from the real rulesmd, loads `ZEP` art-guarded (ORCA/BEAG fallback), draws the raised sprite + ground shadow (NEW render work), and adds the `--demo-aircraft` gate (scripted takeoff→fly→attack→resume, FNV `aircraft_hash` folded at four checkpoints, two-run compute-and-self-compare, wedge guards exit 1). `world_hash` is NOT touched (strategy (a): flight fields hashed ONLY by `aircraft_hash`).

### Approved scope decisions (spec §Approved scope decisions)

- **Flight model:** straight-line travel at cruise altitude ignoring ground pathing/occupancy (no A*, no `passable_` test, no `occ_` reservation while airborne). Facing turns toward travel at the type's turn rate. The exemplar uses the **Jumpjet locomotor** (CLSID `{92612C46-F71F-11d1-AC9F-006008055BB5}`); the per-frame speed/turn model is `[RE-GATE: aircraft.md §1]`.
- **Altitude:** an `altitude` field on the `Unit` (leptons). Takeoff ascends ground→cruise at `JumpjetClimb`; descend at `JumpjetCrash`. Cruise = `JumpjetHeight=750` leptons for ZEP. Rates/behavior `[RE-GATE: aircraft.md §2]`.
- **Altitude render:** the flyer is drawn raised by a screen-y offset proportional to `altitude` (reusing the voxel raster + the `level*level_px` up-shift mechanism); a ground shadow is drawn at the ground cell (altitude 0). Offset formula + shadow convention `[RE-GATE: aircraft.md §3]` — fallback (spec §5, voxel-render.md §6): `dy = (altitude/256)·36.74` → ~107 px at `JumpjetHeight=750`.
- **Air-to-ground:** the flyer acquires a GROUND target, flies to within weapon `Range` (BlimpBomb `Range=1.5`), and fires from cruise via the EXISTING `commit_attack_target`/`try_fire` path (`OmniFire` → no turret aim gate). Fire-from-cruise vs descend-to-attack `[RE-GATE: aircraft.md §4]`; a **simplified direct instant-hit air-to-ground weapon** (as ground vehicles already use, voxel-render.md §7) is acceptable — bomb ballistics deferred.
- **Exemplar:** Kirov Airship `[ZEP]` (Soviet, image `ZEP`, art PRESENT `zep.vxl`/`zep.hva`). Art-guarded; if ZEP art ever regresses, the guard drops to another present flyer (`ORCA`/`BEAG` art verified present) with the demo script adjusted; the flight logic is exemplar-independent and covered by pure tests regardless.
- **Spawn:** CB-2 spawns the exemplar directly (like CB-1 spawned the HTK); no airfield build-from-sidebar. Production-queue wiring is a carry-forward.
- **Verification:** new deterministic gate `--demo-aircraft` (the 10th) + `aircraft_hash` (FNV over flight path + altitude + attack state across takeoff→fly→attack→(descend), two-run compute-and-self-compare, NO pinned literal) + wedge guards (§7): a takeoff AND airborne flight AND an air-to-ground hit must actually happen, else exit 1.
- **Byte-identity:** Strategy (a): flight fields excluded from `world_hash`; a new `step_flight` early-returns behind `aircraft_any_`; every new guard is an added clause provably false in every existing demo (§8). Ground-unit movement/occupancy stays bit-identical.
- **Decomposition tripwire (spec §2):** if the altitude-render/shadow work (§5) or the takeoff/descend state machine fans past the enumerated sites and pushes the plan past ~9 tasks, the phase splits at the natural seam — **(A) flight-foundation** (Tasks 1–3, 5; a gate that only takes off, cruises, lands, no combat) then **(B) air-to-ground-combat** (Tasks 4, 6). This plan lands at **7** — the enumerated guard sweep is 6 one-clause sites folded into Task 3, the render is one draw-path change folded into Task 5; the tripwire holds. Default is the single coherent phase below.

```cpp
#include "flight.hpp"

#include <cmath>

namespace ra2engine {

double step_altitude(double altitude, double target, double max_delta) {
    const double d = target - altitude;
    if (std::fabs(d) <= max_delta) return target;      // no overshoot: land exactly
    return altitude + (d > 0.0 ? max_delta : -max_delta);
}

bool cruise_step(double& fx, double& fy, double gx, double gy, double max_step) {
    const double dx = gx - fx;
    const double dy = gy - fy;
    const double dist = std::sqrt(dx * dx + dy * dy);
    if (dist <= max_step || dist == 0.0) {             // arrival: snap exactly
        fx = gx;
        fy = gy;
        return true;
    }
    fx += dx / dist * max_step;                        // straight-line advance
    fy += dy / dist * max_step;
    return false;
}

double heading_toward(double body_facing, double dx, double dy,
                      double max_turn, bool omni_fire) {
    if (omni_fire) return body_facing;                 // OmniFire: never turns
    if (dx == 0.0 && dy == 0.0) return body_facing;    // degenerate direction
    const double want = facing_u16_from_delta(dx, dy);
    return turn_toward(body_facing, want, max_turn);   // shortest arc, exact land
}

int altitude_to_screen_dy(double altitude) {
    // [RE-GATE: aircraft.md §3 -- fallback: the voxel up/z term is ~36.74 px
    // per cell-of-z (voxel-render.md §6), so dy = (altitude/256) * 36.74.]
    if (altitude <= 0.0) return 0;
    return static_cast<int>(std::lround(altitude / 256.0 * 36.74));
}

FlightState advance_flight_state(FlightState state, double altitude,
                                 double cruise_altitude) {
    if (state == FlightState::TakingOff && altitude >= cruise_altitude)
        return FlightState::Cruising;
    if (state == FlightState::Descending && altitude <= 0.0)
        return FlightState::Grounded;
    return state;
}

}  // namespace ra2engine
```

```cpp
void World::step_flight(double dt) {
    // FIREWALL (spec §8): until the first aircraft is ordered, this whole
    // function is one branch -- the only cost every existing demo pays.
    if (!aircraft_any_) return;

    for (Unit& u : units_) {
        if (!u.is_aircraft) continue;
        if (!u.alive || u.die_time >= 0.0) continue;
        if (u.flight_state == FlightState::Grounded) continue;  // parked: nothing to do

        // 1) Altitude: ascend toward cruise (TakingOff) / descend toward 0
        //    (Descending) at the state's rate; hold at cruise when Cruising
        //    [RE-GATE: aircraft.md §2].
        const bool descending = (u.flight_state == FlightState::Descending);
        const double target = descending ? 0.0 : u.cruise_altitude;
        const double rate = descending ? u.descend_rate : u.climb_rate;
        u.altitude = step_altitude(u.altitude, target, rate * dt);
        u.flight_state = advance_flight_state(u.flight_state, u.altitude, u.cruise_altitude);

        // 2) Cruise translation ONLY once airborne (Cruising): turn toward the
        //    goal, then advance straight-line. The unit does not translate
        //    while still climbing (TakingOff) [spec §3.2]. cell_x/cell_y track
        //    the ground projection of fx/fy for the shadow anchor + combat
        //    range, but claim NO occupancy [spec §4].
        if (u.flight_state == FlightState::Cruising && u.has_flight_goal) {
            const double gx = static_cast<double>(u.flight_goal_x);
            const double gy = static_cast<double>(u.flight_goal_y);
            u.body_facing = heading_toward(u.body_facing, gx - u.fx, gy - u.fy,
                                           u.flight_turn * dt, u.omni_fire);
            const bool arrived = cruise_step(u.fx, u.fy, gx, gy, u.flight_speed * dt);
            u.cell_x = static_cast<int>(std::lround(u.fx));
            u.cell_y = static_cast<int>(std::lround(u.fy));
            if (arrived) u.has_flight_goal = false;   // hover at the goal (BalloonHover)
```

```cpp
void draw_ground_shadow(void* sdl_renderer, double fx, double fy, int level,
                        int width_px, const Camera& cam, int view_w, int view_h) {
    SDL_Renderer* renderer = static_cast<SDL_Renderer*>(sdl_renderer);
    int cx, cy;
    tile_center_screen(fx, fy, level, cam, cx, cy);
    const int w = width_px > 0 ? width_px : kTileW;
    const int hh = w / 4;                         // 2:1 iso, half-height of the blob
    if (cx + w < 0 || cy + hh < 0 || cx - w >= view_w || cy - hh >= view_h) return;
    SDL_SetRenderDrawBlendMode(renderer, SDL_BLENDMODE_BLEND);
    SDL_SetRenderDrawColor(renderer, 0, 0, 0, 110);   // dark, translucent
    // Filled iso diamond: horizontal scanlines whose half-width tapers to 0.
    for (int dy = -hh; dy <= hh; ++dy) {
        const int hw = (w / 2) * (hh - (dy < 0 ? -dy : dy)) / (hh == 0 ? 1 : hh);
        SDL_Rect row{cx - hw, cy + dy, 2 * hw + 1, 1};
        SDL_RenderFillRect(renderer, &row);
    }
}
```

```cpp
// FNV fold of the flight-phase state [spec §7]: every unit's (cell_x, cell_y,
// alive, hp) PLUS each aircraft's (round(altitude), flight_state, target) and
// the occupancy-held count for airborne units (must be 0). Folded at the
// demo's four fixed checkpoints (post-takeoff, post-fly, post-attack, end). A
// NEW accumulator; world_hash and every prior *_hash UNTOUCHED.
uint64_t aircraft_fold(uint64_t h, const ra2engine::World& world) {
    const std::vector<ra2engine::Unit>& us = world.units();
    for (const ra2engine::Unit& u : us) {
        h = fnv_mix(h, static_cast<uint64_t>(u.cell_x));
        h = fnv_mix(h, static_cast<uint64_t>(u.cell_y));
        h = fnv_mix(h, static_cast<uint64_t>(u.alive ? 1 : 0));
        h = fnv_mix(h, static_cast<uint64_t>(u.hp));
    }
    for (const ra2engine::Unit& u : us) {
        if (!u.is_aircraft) continue;
        h = fnv_mix(h, static_cast<uint64_t>(std::llround(u.altitude)));
        h = fnv_mix(h, static_cast<uint64_t>(static_cast<int>(u.flight_state)));
        h = fnv_mix(h, static_cast<uint64_t>(u.target + 1));
    }
    // Airborne units own NO cell [spec §7 step 2].
    uint64_t airborne_cells = 0;
    const ra2engine::Occupancy& occ = world.occupancy();
    for (int y = 0; y < occ.height(); ++y)
        for (int x = 0; x < occ.width(); ++x) {
            const int o = occ.at(x, y);
            if (o >= 0 && o < static_cast<int>(us.size()) && us[o].is_aircraft &&
                us[o].flight_state != ra2engine::FlightState::Grounded)
                ++airborne_cells;
        }
    h = fnv_mix(h, airborne_cells);
    return h;
}
```

```cpp
        char b[176];

                      aa.id.c_str(), aa.va.combat.cruise_altitude, aa.va.combat.flight_speed,
                      aa.va.combat.climb_rate, aa.va.combat.omni_fire ? "yes" : "no");

    const double dt = 1.0 / 15.0;
    long frame = 0;
    bool took_off = false, cruised_airborne = false;
    int hits = 0;
    int prev_hp = world.units()[tgt_idx].hp;
    uint64_t h = 0xcbf29ce484222325ull;         // FNV-1a offset basis

    auto airborne_occ = [&]() {
        int held = 0;
        const ra2engine::Occupancy& occ = world.occupancy();
        for (int y = 0; y < occ.height(); ++y)
            for (int x = 0; x < occ.width(); ++x) {
                const int o = occ.at(x, y);
                if (o == z_idx && world.units()[z_idx].flight_state != ra2engine::FlightState::Grounded)
                    ++held;
            }
        return held;
    };
    auto step_one = [&]() {
        world.step(dt);
        const ra2engine::Unit& z = world.units()[z_idx];
        if (z.flight_state != ra2engine::FlightState::Grounded && z.altitude > 0.0)
            took_off = true;
        if (z.flight_state == ra2engine::FlightState::Cruising && z.altitude > 0.0 &&
            airborne_occ() == 0)
            cruised_airborne = true;
        const int hp = world.units()[tgt_idx].hp;
        if (hp < prev_hp) { ++hits; }
        prev_hp = hp;
        ++frame;
        if (render) {
            SDL_SetRenderDrawColor(ren, 10, 20, 60, 255);
            SDL_RenderClear(ren);
            render_world(ren, *tc, a, ua, world, *cam, W, H, nullptr, &vlist);
        }
    };

    // 1) TAKEOFF: order a move -> release cell, ascend to cruise.
    world.order_unit_move(z_idx, pc->x, pc->y);        // takeoff in place
    if (render) { step_one(); capture_png(ren, start_png, W, H); }
    while (frame < 600 && world.units()[z_idx].flight_state != ra2engine::FlightState::Cruising)
        step_one();
    h = aircraft_fold(h, world);                        // checkpoint 1: post-takeoff
    {
        char b[120];
        std::snprintf(b, sizeof b, "[air] takeoff alt=%.0f/%.0f cell_released=%s frame=%ld",
                      world.units()[z_idx].altitude, aa.va.combat.cruise_altitude,
                      airborne_occ() == 0 ? "yes" : "no", frame);
        r.witness.emplace_back(b);
    }

    // 2) FLY: cruise straight to a distant cell (over any obstacle).
    world.order_unit_move(z_idx, pc->x + 14, pc->y + 10);
    while (frame < 2400 && world.units()[z_idx].has_flight_goal) step_one();
    h = aircraft_fold(h, world);                        // checkpoint 2: post-fly
    {
        char b[128];
        std::snprintf(b, sizeof b, "[air] cruise arrived=(%d,%d) alt=%.0f occ_held=%d frame=%ld",
                      world.units()[z_idx].cell_x, world.units()[z_idx].cell_y,
                      world.units()[z_idx].altitude, airborne_occ(), frame);
        r.witness.emplace_back(b);
    }

    // 3) ATTACK: order the aircraft to attack the ground target; fly to range
    //    and fire until it dies.
    world.clear_selection();
    world.units()[z_idx].selected = true;
    world.order_attack(tgt_idx);
    while (frame < 5000 && world.units()[tgt_idx].alive &&
           world.units()[tgt_idx].die_time < 0.0)
        step_one();
    h = aircraft_fold(h, world);                        // checkpoint 3: post-attack
    {
        char b[120];
        std::snprintf(b, sizeof b, "[air] hit target=%d hits=%d target_dead=%s frame=%ld",
                      tgt_idx, hits,
                      (!world.units()[tgt_idx].alive || world.units()[tgt_idx].die_time >= 0.0)
                          ? "yes" : "no",
                      frame);
        r.witness.emplace_back(b);
    }

    // 4) RESUME: fixed window; the Kirov holds cruise (BalloonHover).
    const long resume_until = frame + 150;
    while (frame < resume_until) step_one();
    h = aircraft_fold(h, world);                        // checkpoint 4: end
    r.hash = h;

    {
        char b[128];
        std::snprintf(b, sizeof b, "[aircraft] final took_off=%s cruised=%s hits=%d frame=%ld",
                      took_off ? "yes" : "no", cruised_airborne ? "yes" : "no", hits, frame);
        r.witness.emplace_back(b);
    }
    char hb[64];
    std::snprintf(hb, sizeof hb, "[aircraft] aircraft_hash=%016llx",
                  static_cast<unsigned long long>(r.hash));
    r.witness.emplace_back(hb);

    // Wedge guards [spec §7]: the gate can never pass vacuously.
    if (!took_off) { r.ok = false; r.witness.emplace_back("[aircraft] WEDGE: no takeoff"); }
    if (!cruised_airborne) {
        r.ok = false;
        r.witness.emplace_back("[aircraft] WEDGE: no airborne cruise with occ_held=0");
    }
    if (hits < 1) {
        r.ok = false;
        r.witness.emplace_back("[aircraft] WEDGE: no air-to-ground hit");
    }
    if (render) { capture_png(ren, end_png, W, H); }   // capture the ALREADY-rendered frame
    return r;
}
```
