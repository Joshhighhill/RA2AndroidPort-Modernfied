```cpp
std::vector<int> Rules::verses(const std::string& warhead) const {
    // Verses=100%,80%,... -> percent ints, one per armor class, in ini order.
    // Tolerates spaces and a missing '%' (the game's parser reads the number).
    std::vector<int> out;
    std::string s = ini_->get(warhead, "Verses", "");
    if (s.empty()) return out;
    size_t pos = 0;
    while (pos <= s.size()) {
        size_t comma = s.find(',', pos);
        std::string tok = s.substr(pos, comma == std::string::npos ? std::string::npos : comma - pos);
        size_t b = tok.find_first_not_of(" \t");
        size_t e = tok.find_last_not_of(" \t%");
        out.push_back(b == std::string::npos ? 0 : std::atoi(tok.substr(b, e - b + 1).c_str()));
        if (comma == std::string::npos) break;
        pos = comma + 1;
    }
    return out;
}
```

**Semantics implemented by `step_combat` (each is a test below):**
- Constants: `kLogicFps = 15.0` (ROF frames → seconds), `kLeptonsPerCell = 256.0`, `kGuardStray = 2.0` cells (pursuit slack past weapon range for auto-acquired targets — Task 1 §Decisions may amend), `kDieAnimSecs = 1.0` (renderer-tuned in Task 7), `kFireFlashSecs = 0.4`.
- Range check (default per ModEnc, Task 1 confirms metric): euclidean on lepton coords — `hypot((tx-fx)*256,(ty-fy)*256) <= w_range*256`.
- Target priority: keep valid current target > (if just damaged and idle) retaliate vs attacker > auto-acquire nearest hostile in range (ties: lowest index).
- Explicit `attack_order` targets are pursued indefinitely (MoveRequest toward the target's cell whenever out of range and the requested goal is stale); auto-acquired targets are dropped when beyond `w_range + kGuardStray` of the guard anchor, with a MoveRequest back to the anchor.
- Fire: when in range and `rof_cool <= 0` — `rof_cool = w_rof / kLogicFps`, `fire_flash = kFireFlashSecs`, victim `hp -= damage_vs(w_damage, w_verses, victim.armor_ix)`; if the victim is idle (no target), it retaliates (`target = attacker`). Victim at `hp <= 0`: `die_time = 0`, occupancy released, its own target cleared. A dying/dead unit is never a valid target; validation clears stale targets.
- Dying: `die_time` accumulates; at `>= kDieAnimSecs` → `alive = false`. Dying units don't move, fire, or occupy.
