# P7 Save / Load — plan

Spec: `docs/superpowers/specs/2026-10-06-saveload-design.md`.
Testing rule: build + scoped `ra2assets_tests -tc="saveload*"` per task; only
`--demo-saveload` is run as a gate; the full suite/gates run once at the end
by the controller. Commit after every task.

1. **Archive core** — `engine/savegame.hpp/.cpp`: Writer/Reader, generic `io`,
   aggregate-arity helper. Tests: primitive/string/vector/map round trip,
   truncated input fails cleanly, arity of a toy struct.
2. **Struct visitors** — every public aggregate reachable from World
   (Unit, Building, BuildingTypeDef, UnitCombat, UnitTypeDef, ProjectileSpec,
   ProjectileRules, ProjRng, OreRng, Projectile, ProjectileEvent, CargoEvent,
   QueueSlot, ProductionState, Superweapon, RepairSellRules, AI structs,
   aimd structs, SeqEntry/UnitAnimSeq, HouseRec, SkirmishSlot/Config).
   Tests: arity == visited count for each.
3. **World / OreField / Occupancy / ProductionQueues** — `friend struct
   SaveAccess;` lines; `save_world(const World&)` / `load_world(World&, bytes)`.
   Tests: rich-world round trip + step-K byte identity; sizeof pins.
4. **MapTriggerSystem** — friend line; `save_triggers` / `load_triggers`.
   Test: run a parsed trigger set K ticks, save, load into a fresh system,
   tick both, compare `state_hash` + log + re-save bytes.
5. **Container + slots** — header, sections, `SAVE%04X.SAV` naming, list
   newest-first, version check, delete. Tests on a temp dir.
6. **Gate** `--demo-saveload` in main.cpp (skirmish + triggers scenarios).
7. **GameScene save/load + UI** — `SceneSave`, in-game options overlay,
   Load/Save/Delete dialog, main-menu Load Saved Game.
8. **Finalize** — README section + gate row, ledger entry.
