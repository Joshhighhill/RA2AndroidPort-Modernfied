# Android touch test 21 — vanilla behavior corrections

Built from the restored 900020 development baseline, preserving its Chrono Miner rendering lifetime fix. This is an incremental test release, not a claim of full Yuri parity.

## Gameplay

- Restrict appended Yuri buildings to actual supported vanilla structures. Shared scenery and dormant prototypes no longer enter the roster merely because Owner includes YuriCountry.
- Deploying Yuri retains controlled units.
- Attached slaves reject player commands and cannot be selected, including while their miner is packed. Internal mining movement still works. Freed slaves remain selectable and commandable by their new owner; a regression covers survivors transferring to the enemy unit that killed their miner.
- Resolve worker pickup cadence from SLAV HarvestRate and manager unloading cadence from SlaveReloadRate. Standard truck miners retain their existing timing.
- Honor LandTargeting=2 when choosing a land weapon: Boomer uses CruiseLauncher instead of its torpedo. Tests exercise explicit V3 and Boomer orders through missile spawning. V3 has no separately confirmed production-path fix in this release.

## Controls and reports

- Panel starts collapsed. ATK MOVE arms the next ground tap through the existing original-controls attack-move path; ordinary ground taps remain movement.
- Placement cancellation reaches the input handler after a preview tap.
- Panel hides while multiplayer chat is open. Group buttons and fold arrow have 56-pixel height. Updated phone documentation and play-script targets.
- Engine report writes are buffered, with a checkpoint about once per second when writing and an explicit flush before in-game report sharing. Normal builds no longer trace archive lookups; RA2_TRACE_ASSETS=1 opts in. Diagnostics startup and game-file auto-start remain available.

## Validation

- Native suite using the supplied PC installation: 1190 tests passed, 266400 assertions; one fixture test excluded because it requires the absent optional ecache01.mix archive. The initial unfiltered run exposed this fixture assumption and an outdated slave-unloading expectation, which was corrected to use the configured reload interval.
- Standalone production touch-handler harness passed. Android C++ syntax check passed with the existing waypoint_cell override warning.
- Play scripts updated but not executed against a rendered phone session. Visual correctness, heat and frame pacing require device validation.

## Compatibility and remaining work

Save format is 52 because the two resolved slave timing values are serialized. Older saves remain on disk and are listed as an older version; they cannot be loaded in this build. Preserve the previous APK if finishing an old match.

Still open: Tank Bunker occupant position/layers and exit behavior on device, Slave Miner undeploy animation, smooth ramp height/tilt, particles and firing effects, blocked-worker recovery and crowding, passive land acquisition rules, original-menu text rendering, and complete implementation of unsupported Yuri/Soviet powers. Psychic Dominator, Genetic Mutator, Force Shield and Spy Plane must not be enabled merely by adding enum mappings: their effects, prerequisites, targeting, visuals and save state need implementation and tests first.

No retail game assets are included. Original game files are used read-only as local fixtures. No Ares/Phobos C++ or Windows DLL code is copied into this native Android build.
