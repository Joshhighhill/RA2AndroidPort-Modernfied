# Android touch test 22 - rendering and animation foundations

## Corrections

- Each voxel part (hull, turret, barrel and alternate turret) now uses its own HVA frame count. A common cycle based on the longest part could repeat shorter-part frames unevenly. GPU and CPU cache keys use the actual normalized frame for that part.
- Reset walk stages and rules-dependent animation caches for a new match. WalkRate and IdleRate come from the unit rules ID, including types whose Image differs. Frozen units do not keep advancing their vehicle walk stage.
- Reset cached charge/IFV turret choices, jumpjet wobble rules and damage-fire lists between match rule sets.
- Replace the unbounded CPU cache of animated/sloped/pitched voxel variants with a per-asset cache using an estimated 8 MiB soft budget. Reclaim cold variants only at frame boundaries. Preserve current and previous-frame working sets, even above budget, to avoid invalid references and repeated rasterization of a busy scene. This is not a total renderer memory cap; base facings, textures and active working sets are separate.
- VOXEL_CACHE diagnostics report estimated animated-variant CPU bytes, variant count and evictions about every 10 seconds of simulation while rendering. These counters do not measure GPU execution time or phone temperature.

## Compatibility and scope

Save format remains 52: build 900021 saves remain compatible. This rendering pass does not change unit gameplay state or the save schema. Older format-51 saves from 900020 still require their original build.

Tank Bunker occupant offsets/layers and entry/exit, Slave Miner undeploy art, smooth slope movement, infantry-specific animation faults and missing weapon particles still require reproduction and correction. These are not claimed fixed by the animation-clock/cache changes. Submit the report ZIP with map/unit details and a short video for visual problems.

No retail assets are bundled or modified. Only the Omar-based native Android project was edited; the separate StillM8 project is unchanged.
