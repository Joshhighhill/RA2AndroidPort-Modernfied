# Gap analysis 05 — Rendering, audio and presentation in REAL play

Read-only audit of what the interactive game (`run_menu` → `GameScene`,
`engine/main.cpp:4343-5257`) actually draws and plays every frame, versus the
original RA2 (Allied/Soviet). Everything below was traced through the
interactive code path (`GameScene::update` / `GameScene::render` →
`render_world` `main.cpp:2769`, `draw_sidebar` `main.cpp:3579`,
`draw_terrain`/`draw_unit` `engine/iso_renderer.cpp`). Gate-only code is
flagged as such. Evidence images: the gate screenshots in this and the
`d44bece6` session scratchpads (`demo_campaign_all01t_start.png`,
`demo_roster2_start.png`, `demo_abilities_mid.png`, `demo_projectile_mid.png`,
`demo_ai_base_end.png`). No interactive screenshot was taken because the gate
batch was still running (`gate_results.txt` had no `ALL DONE`) for the whole
audit; nothing in this file depends on one.

Status legend: WORKS / GATE-ONLY / PARTIAL / WRONG / BROKEN / MISSING.
Severity: BLOCKER (unplayable or core loop broken) / MAJOR / MINOR.
Effort: S (< 1 day) / M (1-3 days) / L (> 3 days).

## Top 10 blockers (presentation)

1. **No EVA except "Unit lost"** — no construction-complete / unit-ready / low-power / insufficient-funds / base-under-attack feedback; `evamd.ini` unparsed (`main.cpp:592-646, 4821`).
2. **Most units are mute** — voices/reports resolved only for E1/E2/HTNK (`main.cpp:592`); the player's Allied tanks and infantry other than GI make no sound.
3. **No in-game music** — `theme.ini` never read; only the menu Grinder loop exists (`main.cpp:5392`).
4. **No impact/explosion animations or sounds** — no `AnimList` system; shells are coloured squares that vanish on hit (`main.cpp:2741-2767`); nukes are instant and invisible.
5. **Enemy buildings, ore and crates are drawn through the shroud** — no visibility test in `draw_building`/`draw_ore`/`draw_p5_crates` (`main.cpp:2346, 2544, 2688`); shroud itself is a staircase of black rectangles with no `shroud.shp` edges (`iso_renderer.cpp:148-153`).
6. **Buildings are static** — no ActiveAnim/IdleAnim/Bib/TurretAnim/damage fire (grep `engine/`), so bases look dead and defences cannot show a turret.
7. **House colours wrong beyond 2 players** — voxels red for every house ≠ 0 (`main.cpp:2460`), SHP/buildings blue for every house ≠ 1 (`world.cpp:296-310`); the 8-MP-colour `house_palette` is only used by the minimap.
8. **Theater art hardcoded to TEMPERATE** for buildings, ore and the unit palette (`main.cpp:286, 1079, 1909, 1936`) — snow/urban/desert maps render tiles correctly but temperate structures.
9. **Maps are barren** — `[Terrain]` trees, non-ore overlays (walls/bridges/fences), `[Smudge]` and (in skirmish) neutral `[Structures]` are never spawned or drawn (`maps.md §4.7/§5`).
10. **Only the repair/sell cursors exist** — attack/move/no-go/enter/deploy/scroll cursors fall back to the OS arrow (`main.cpp:3796-3836, 4871`); together with the 5× movement speed (`main.cpp:675`) and the placeholder minimap (`main.cpp:3541`) the game gives little feedback about what a click will do.
