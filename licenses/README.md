# Runtime notice provenance

`LIBCXX-LICENSE.txt` is the unmodified LLVM libc++ license from
https://github.com/llvm/llvm-project/blob/llvmorg-18.1.8/libcxx/LICENSE.TXT
(retrieved 25 October 2026). It contains the Apache 2.0 license, LLVM
exceptions and legacy notices supplied by LLVM. The APK links the existing
Android NDK r27c `libc++_shared.so`; no runtime was replaced by this notice.

The engine's root LICENSE remains 0BSD and has not been changed. SDL and stb
notices remain in THIRD_PARTY_NOTICES.md. See CREDITS.md for attribution.
